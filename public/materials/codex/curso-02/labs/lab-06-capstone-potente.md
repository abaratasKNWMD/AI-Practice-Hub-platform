# Lab 06: capstone potente

## Objetivo

Completar una feature pequeña usando Codex como plataforma: contexto, modelo, tools, permisos, verificación, review y coste.

## Inputs

- Repo real o de práctica.
- Una feature pequeña pero no trivial.
- Plantilla `decision-modelo.md`.
- Rúbrica `review-codex.md`.
- Registro `registro-coste.csv`.

## Entregables

- Brief inicial.
- Decisión de modelo/reasoning/permisos.
- Plan.
- Diff.
- Tests o evidencia equivalente.
- Review.
- Nota de coste.
- Propuesta de actualización para AGENTS.md, skill o plantilla.

## Evaluación

| Criterio | Excelente | Insuficiente |
| --- | --- | --- |
| Contexto | rutas, restricciones y done claros | prompt genérico |
| Verificación | test/captura/build real | "parece correcto" |
| Coste | mide y justifica | usa máximo sin pensar |
| Gobierno | permisos y tools explicados | autonomía sin límites |
| Reutilización | deja artefacto | se queda en demo |
