# Kit potente del Curso 2: Codex plataforma, agentes y GPT-5.5

Este paquete acompaña el curso avanzado. No es material decorativo: son archivos para abrir durante la clase, pedir a Codex que los use y terminar cada bloque con un artefacto reutilizable.

## Ruta recomendada de uso

1. `prompts-potentes.md`: muestra cómo pedir trabajo avanzado sin quemar contexto.
2. `plantillas/decision-modelo.md`: aterriza modelo, reasoning, permisos y coste.
3. `plantillas/config-codex.example.toml`: enseña configuración por capas, MCP, permisos y subagentes.
4. `ejemplos/session-cost-audit/`: ejecuta una auditoría simple de una sesión para hablar de tokens, herramientas e imágenes.
5. `ejemplos/mcp-readonly-docs/`: laboratorio de MCP local read-only para entender herramientas gobernadas.
6. `skills/qa-visual-codex/SKILL.md`: ejemplo de skill pequeña y accionable.
7. `labs/`: guiones para impartir las prácticas del módulo 7.

## Principios

- Codex potente no significa más autonomía sin control.
- Cada workflow debe declarar contexto, herramientas, permisos, modelo y evidencia.
- Si un patrón se repite, debe vivir en AGENTS.md, una plantilla, una skill o una configuración de proyecto.
- Si algo toca red, credenciales, producción, datos personales o dinero, sube el nivel de revisión humana.

## Fuentes

La estructura del kit sigue documentación oficial consultada el 06/05/2026: Codex best practices, config reference, MCP, skills y subagents. Revisa modelos, disponibilidad y precios antes de impartir de nuevo.
