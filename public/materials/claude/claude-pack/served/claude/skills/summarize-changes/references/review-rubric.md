# Review rubric

Use this rubric before saying a change is ready:

- Correctness: does the behavior match the request?
- Scope: are unrelated files untouched?
- Evidence: was lint, typecheck, build or a targeted test executed?
- Security: could data, auth or tool permissions be affected?
- Cost: did the agent spend context on stale files or oversized outputs?
- Handoff: can another developer understand the diff without chat history?
