# Memory policy

## What belongs in CLAUDE.md

- Stable architecture facts.
- Build and test commands.
- Team conventions.
- Safety rules that should apply in every session.

## What belongs in rules

- File-type or path-specific guidance.
- Frontend, backend, testing and security conventions.

## What belongs in skills

- Repeatable workflows with steps.
- Review rubrics.
- Templates and scripts.

## What belongs in auto memory

- Preferences discovered during work.
- Debugging facts that are local to the machine.
- Temporary lessons that can be audited with `/memory`.
