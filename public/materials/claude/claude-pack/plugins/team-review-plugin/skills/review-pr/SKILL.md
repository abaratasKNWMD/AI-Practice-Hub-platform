---
description: Review a pull request from diff and repository policy. Use when the user asks for PR review, merge readiness, or risk summary.
---

## Inputs to gather

- Current branch diff.
- Linked issue or PR description.
- Test results.
- Relevant policy files.

## Output

Return findings first:

- Severity.
- File/path.
- Why it matters.
- Suggested fix.

Then add residual risk and missing evidence.
