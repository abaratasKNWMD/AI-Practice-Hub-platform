# Review instructions

When reviewing code:

- Lead with bugs, regressions, security issues and missing tests.
- Cite concrete files and lines when possible.
- Separate findings from questions and suggestions.
- Do not comment on formatting unless it hides risk.
- Include residual risk if the change cannot be verified.
