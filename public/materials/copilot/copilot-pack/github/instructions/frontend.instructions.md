# Frontend instructions

- Use semantic HTML before custom ARIA.
- Keep text readable on mobile and desktop.
- Do not overlap text with controls or images.
- Prefer existing UI components before adding new patterns.
- Use icons for tool actions when there is a familiar symbol.
- Verify console, loading states, empty states and responsive layout.
