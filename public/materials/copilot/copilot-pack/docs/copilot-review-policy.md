# Copilot Review Policy

## Purpose

Use Copilot code review to catch concrete risk before human review, not to create decorative comments.

## Review priorities

1. Correctness.
2. Security.
3. Tests.
4. Accessibility.
5. Performance.
6. Maintainability.

## Rules

- Copilot suggestions are advisory.
- A human owns the merge decision.
- Reviews should cite evidence.
- Re-review after meaningful changes.
- Do not block merges on style-only comments unless the repository policy says so.
