## Objetivo

Lee el agente de ejemplo y prepara el esqueleto minimo para ejecutar una review programatica.

## Tareas

1. Abrir src/index.ts.
2. Identificar prompt, tools y agents.
3. Definir variables de entorno necesarias.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
