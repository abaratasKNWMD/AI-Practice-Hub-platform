# Routing de modelos por coste

Vendor: claude
Curso: Claude Operator
Duracion: 30 min
Superficie: Model picker
Modelo recomendado: Haiku + Sonnet + Opus
Permisos: governance
Coste estimado: bajo: diseño de politica

## Objetivo

Diseña una tabla que asigne Haiku, Sonnet u Opus segun tarea, riesgo y coste esperado.

## Tareas

1. Listar 10 tareas frecuentes.
2. Asignar modelo recomendado.
3. Definir cuando escalar o degradar.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
