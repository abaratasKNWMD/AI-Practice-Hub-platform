# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Listar 10 tareas frecuentes.
2. Asignar modelo recomendado.
3. Definir cuando escalar o degradar.

## Solucion esperada

La tabla debe reservar Opus para arquitectura/debugging critico, Sonnet para implementacion y Haiku para resumen/clasificacion.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
