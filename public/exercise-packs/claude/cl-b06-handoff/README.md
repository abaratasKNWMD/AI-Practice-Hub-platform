# Handoff listo para tutoria

Vendor: claude
Curso: Claude Basic
Duracion: 30 min
Superficie: Handoff
Modelo recomendado: Haiku
Permisos: read-only
Coste estimado: bajo

## Objetivo

Convierte una sesion en una ficha para que un profesor pueda revisar la duda en tutoria sin repetir todo.

## Tareas

1. Completar plantilla de handoff.
2. Marcar riesgo pendiente.
3. Escribir el prompt de continuacion.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
