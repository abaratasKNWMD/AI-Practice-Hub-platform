# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Definir trigger pull_request.
2. Limitar permisos de token.
3. Escribir salida esperada como comentario de PR.

## Solucion esperada

La Action propuesta debe leer diff, aplicar rubrica, comentar findings y dejar claro que la aprobacion humana sigue siendo necesaria.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
