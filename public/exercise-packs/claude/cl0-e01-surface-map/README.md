# Mapa de superficies Claude Code

Vendor: claude
Curso: Claude Code Orientation
Duracion: 20 min
Superficie: Claude Code CLI
Modelo recomendado: Sonnet
Permisos: read-only
Coste estimado: bajo: solo lectura y resumen

## Objetivo

Construye un mapa de que parte del trabajo pertenece a memoria, skills, subagentes, hooks, MCP, plugins y SDK.

## Tareas

1. Leer las fuentes oficiales enlazadas.
2. Clasificar cada feature por uso: contexto, accion, extension o automatizacion.
3. Cerrar con una regla de decision para el equipo.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
