# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Leer las fuentes oficiales enlazadas.
2. Clasificar cada feature por uso: contexto, accion, extension o automatizacion.
3. Cerrar con una regla de decision para el equipo.

## Solucion esperada

Un mapa correcto separa memoria persistente, skills invocables, subagentes con contexto separado, hooks deterministicos, MCP como conectores y Agent SDK como superficie programatica.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
