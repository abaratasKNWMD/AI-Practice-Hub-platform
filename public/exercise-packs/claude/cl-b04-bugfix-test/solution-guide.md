# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Pedir a Claude plan corto.
2. Ejecutar test o reproduccion minima.
3. Aplicar patch y reejecutar verificacion.

## Solucion esperada

Debe quedar un diff pequeno, un comando de verificacion y una explicacion de por que el bug queda cubierto.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
