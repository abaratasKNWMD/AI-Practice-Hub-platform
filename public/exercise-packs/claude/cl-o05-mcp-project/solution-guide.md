# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Leer .mcp.json.
2. Marcar servidores por riesgo.
3. Definir cuando se activa cada servidor.

## Solucion esperada

El inventario debe listar servidores, permisos, variables, riesgo, owner y criterio de activacion.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
