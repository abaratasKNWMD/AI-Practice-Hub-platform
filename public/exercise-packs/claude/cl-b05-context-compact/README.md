# Compactar sin perder el hilo

Vendor: claude
Curso: Claude Basic
Duracion: 25 min
Superficie: /compact
Modelo recomendado: Sonnet
Permisos: chat command
Coste estimado: bajo: control de contexto

## Objetivo

Simula una tarea larga y prepara el resumen que debe sobrevivir a /compact.

## Tareas

1. Enumerar objetivo, ficheros, decisiones y pruebas.
2. Escribir una compact note.
3. Comparar con el handoff template.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
