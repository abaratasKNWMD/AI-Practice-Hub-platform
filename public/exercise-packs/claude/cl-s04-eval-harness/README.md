# Harness de evaluacion

Vendor: claude
Curso: Claude Agent SDK Enterprise
Duracion: 70 min
Superficie: Evals
Modelo recomendado: Haiku judge + Sonnet worker
Permisos: local sdk
Coste estimado: medio-alto: dataset + judge

## Objetivo

Diseña un mini conjunto de evaluacion para medir si el agente detecta bugs, gaps de test y riesgos.

## Tareas

1. Crear 5 casos sinteticos.
2. Definir expected findings.
3. Calcular precision simple y falsos positivos.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
