# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Leer las cuatro rules de ejemplo.
2. Eliminar duplicacion con CLAUDE.md.
3. Añadir dos reglas especificas por area.

## Solucion esperada

Las rules finales deben reducir ruido del prompt global y activar instrucciones solo cuando el area lo necesita.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
