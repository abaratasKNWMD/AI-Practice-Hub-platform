# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Revisar allowedTools.
2. Crear prompt que prohíba editar.
3. Definir salida con paths y riesgos.

## Solucion esperada

El agente debe funcionar como reviewer read-only y declarar limitaciones cuando necesite ejecutar tests.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
