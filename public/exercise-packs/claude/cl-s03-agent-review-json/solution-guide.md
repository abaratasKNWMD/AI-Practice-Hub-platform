# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Leer rubric.ts.
2. Añadir campos severity, file, issue y fix.
3. Definir verdict con tres estados.

## Solucion esperada

La salida estable debe permitir dashboard, metricas, alertas y evaluacion automatizada.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
