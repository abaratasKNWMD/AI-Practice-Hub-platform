## Objetivo

Genera un CLAUDE.md para un repositorio de practica tras leer su estructura y scripts.

1. Mapear carpetas principales.
2. Detectar comandos en package.json o docs.
3. Escribir memoria con reglas comprobables.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
