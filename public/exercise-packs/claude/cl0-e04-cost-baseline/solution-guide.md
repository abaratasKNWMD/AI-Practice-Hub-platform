# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Abrir la plantilla de auditoria.
2. Definir campos obligatorios para labs.
3. Escribir tres reglas de ahorro para el equipo.

## Solucion esperada

Una baseline aceptable incluye modelo usado, contexto cargado, herramientas, reintentos, snapshot de uso y decision de optimizacion.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
