## Objetivo

Dado un listado de reglas de equipo, decide que va a CLAUDE.md, rules, skills o memoria local.

## Tareas

1. Crear tabla con cuatro columnas.
2. Asignar cada regla a su destino.
3. Marcar que reglas son temporales o personales.

- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
