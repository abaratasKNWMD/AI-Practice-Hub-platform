# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Leer la skill de ejemplo.
2. Ajustar description para el equipo.
3. Probarla sobre un diff real o simulado.

## Solucion esperada

La skill debe producir resumen, ficheros, riesgos y commit message sin volver a escribir el prompt completo.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
