# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Crear matriz de labels.
2. Definir comandos permitidos.
3. Diseñar mensaje de rechazo por riesgo.

## Solucion esperada

El trigger debe incluir labels, actor autorizado, tipo de cambio, presupuesto y fallback humano.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
