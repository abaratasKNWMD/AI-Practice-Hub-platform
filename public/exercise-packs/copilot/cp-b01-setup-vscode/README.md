Vendor: copilot
Curso: Copilot Basic
Duracion: 20 min
Superficie: VS Code
Modelo recomendado: Modelo incluido

Coste estimado: Muy bajo: setup y comprobacion

## Objetivo

Verificar que el alumno tiene Copilot operativo antes de entrar en completions, chat y agent mode.

## Tareas

1. Abrir VS Code.
2. Comprobar extension y login.
3. Probar una completion simple.
4. Registrar incidencias de setup.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
