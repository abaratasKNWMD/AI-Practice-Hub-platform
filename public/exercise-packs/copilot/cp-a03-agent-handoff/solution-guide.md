# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Seleccionar tarea multiarchivo.
2. Planificar con planner.
3. Implementar con implementer.
4. Revisar con reviewer.

## Solucion esperada

La entrega muestra plan, patch, review y verificacion con roles separados.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
