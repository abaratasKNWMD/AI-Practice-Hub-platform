# Handoff planner -> implementer -> reviewer

Vendor: copilot
Curso: Copilot Advanced
Duracion: 60 min
Superficie: VS Code custom agents
Modelo recomendado: Modelo premium si hay alta ambiguedad
Permisos: read-only por rol, write solo implementer
Coste estimado: Medio-alto: varios agentes/iteraciones

## Objetivo

Practicar roles diferenciados sin convertir Copilot en teatro: plan, implementacion y review.

## Tareas

1. Seleccionar tarea multiarchivo.
2. Planificar con planner.
3. Implementar con implementer.
4. Revisar con reviewer.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
