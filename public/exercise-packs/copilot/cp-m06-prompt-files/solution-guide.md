# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Leer el lab de prompts.
2. Crear review.prompt.md.
3. Crear generate-tests.prompt.md.
4. Ejecutar uno sobre un cambio real.

## Solucion esperada

El alumno entrega dos prompt files utiles y una ejecucion demostrada.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
