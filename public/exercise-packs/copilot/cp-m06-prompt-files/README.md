# Prompt files reutilizables

Vendor: copilot
Curso: Copilot Medium
Duracion: 45 min
Superficie: .github/prompts
Modelo recomendado: Modelo incluido o Agent segun prompt
Permisos: read-only -> workspace-write
Coste estimado: Medio: depende del modo y herramientas

## Objetivo

Crear prompts invocables para tests, refactor, review y PR, en vez de reescribir siempre la misma peticion.

## Tareas

1. Leer el lab de prompts.
2. Crear review.prompt.md.
3. Crear generate-tests.prompt.md.
4. Ejecutar uno sobre un cambio real.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
