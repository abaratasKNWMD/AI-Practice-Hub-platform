# Refactor controlado

Vendor: copilot
Curso: Copilot Medium
Duracion: 40 min
Superficie: Copilot Edit / Agent
Modelo recomendado: Modelo incluido o premium segun impacto
Permisos: workspace-write
Coste estimado: Medio: revisar diff y tests

## Objetivo

Practicar refactor sin deriva de comportamiento, con limites y verificacion.

## Tareas

1. Abrir ejercicio de refactoring.
2. Definir que comportamiento no cambia.
3. Aplicar refactor pequeno.
4. Ejecutar test o comparar salida.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
