# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Abrir ejercicio de refactoring.
2. Definir que comportamiento no cambia.
3. Aplicar refactor pequeno.
4. Ejecutar test o comparar salida.

## Solucion esperada

El resultado conserva comportamiento, mejora estructura y queda probado o razonado.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
