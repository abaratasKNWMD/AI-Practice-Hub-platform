# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Leer custom agents lab.
2. Crear planner.agent.md.
3. Limitar tools a read/search.
4. Probar una tarea multiarchivo.

## Solucion esperada

El agente debe proponer plan, riesgos y verificacion sin tocar archivos.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
