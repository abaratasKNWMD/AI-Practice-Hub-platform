# Rama, commit y PR sin bloquear la tutoria

Vendor: copilot
Curso: Git/GitHub Survival para IA
Duracion: 25 min
Superficie: GitHub + VS Code
Modelo recomendado: Modelo incluido / Ask
Permisos: local demo
Coste estimado: Muy bajo: sin premium requests si se trabaja con docs y comandos

## Objetivo

El alumno practica el minimo Git necesario para que Copilot no se convierta en una clase de ramas, forks y PRs.

## Tareas

1. Crear una rama de practica.
2. Hacer un commit pequeno.
3. Abrir o simular un PR.
4. Escribir una descripcion apta para un agente.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
