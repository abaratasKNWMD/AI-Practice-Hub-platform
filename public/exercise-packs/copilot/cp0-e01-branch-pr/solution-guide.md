# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Crear una rama de practica.
2. Hacer un commit pequeno.
3. Abrir o simular un PR.
4. Escribir una descripcion apta para un agente.

## Solucion esperada

La entrega valida incluye rama, commit pequeno, diff entendible y descripcion con objetivo, contexto, restricciones y criterio de cierre.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
