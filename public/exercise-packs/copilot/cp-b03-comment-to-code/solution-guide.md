# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Escribir un comentario vago.
2. Reescribirlo con inputs, outputs y edge cases.
3. Aceptar o editar la completion.
4. Anadir una comprobacion manual o test.

## Solucion esperada

El comentario mejorado produce una funcion mas estable y menos ambigua, con al menos un caso de validacion.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
