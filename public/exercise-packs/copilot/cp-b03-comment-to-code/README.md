# Comentario a codigo verificable

Vendor: copilot
Curso: Copilot Basic
Duracion: 30 min
Superficie: VS Code editor
Modelo recomendado: Modelo incluido
Permisos: workspace-write
Coste estimado: Bajo

## Objetivo

Convertir comentarios vagos en especificaciones pequenas que generen codigo revisable.

## Tareas

1. Escribir un comentario vago.
2. Reescribirlo con inputs, outputs y edge cases.
3. Aceptar o editar la completion.
4. Anadir una comprobacion manual o test.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
