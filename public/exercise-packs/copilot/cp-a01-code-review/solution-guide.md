# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Ejecutar review local sobre diff.
2. Comparar con review sin instrucciones.
3. Anadir review.instructions.md.
4. Re-review y clasificar findings.

## Solucion esperada

La review final prioriza bugs, seguridad, tests y cita evidencia.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
