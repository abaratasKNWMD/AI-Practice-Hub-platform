# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Elegir modulo.
2. Pedir README o docstring con audiencia concreta.
3. Eliminar redundancias.
4. Anadir ejemplo de uso.

## Solucion esperada

La documentacion final ayuda a usar o modificar el modulo, no solo lo describe superficialmente.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
