# De error a fix sin parche gigante

Vendor: copilot
Curso: Copilot Basic
Duracion: 35 min
Superficie: VS Code + terminal
Modelo recomendado: Modelo incluido; premium solo si el error es complejo
Permisos: workspace-write
Coste estimado: Medio-bajo: un diagnostico y un patch

## Objetivo

Convertir un error pegado en un diagnostico y fix minimo con test o comprobacion.

## Tareas

1. Ejecutar o leer el error.
2. Pedir causa probable con archivo.
3. Aplicar fix minimo.
4. Verificar con test/comando.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
