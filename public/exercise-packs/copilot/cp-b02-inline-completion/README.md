# Ghost text con criterio

Vendor: copilot
Curso: Copilot Basic
Duracion: 25 min
Superficie: VS Code editor
Modelo recomendado: Modelo incluido
Permisos: workspace-write
Coste estimado: Bajo: inline suggestions incluidas en planes de pago

## Objetivo

Practicar autocompletado sin aceptar todo por velocidad. El alumno compara una sugerencia mediocre con una guiada por contexto.

## Tareas

1. Abrir el ejercicio de completion.
2. Generar una funcion con contexto minimo.
3. Mejorar nombres y comentario.
4. Comparar la sugerencia antes/despues.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
