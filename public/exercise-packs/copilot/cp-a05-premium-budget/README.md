# Premium request budget

Vendor: copilot
Curso: Copilot Advanced
Duracion: 35 min
Superficie: Copilot billing + modelos
Modelo recomendado: Comparativa modelo incluido vs premium
Permisos: read-only
Coste estimado: Variable: ejercicio de medicion

## Objetivo

Aprender que features/modelos pueden consumir premium requests y que cloud agent tiene coste adicional de Actions.

## Tareas

1. Leer fuentes de requests.
2. Completar log de coste.
3. Clasificar tres tareas por modelo.
4. Definir regla de equipo.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
