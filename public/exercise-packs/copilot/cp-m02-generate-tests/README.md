# Tests con Copilot

Vendor: copilot
Curso: Copilot Medium
Duracion: 45 min
Superficie: VS Code + test runner
Modelo recomendado: Modelo incluido para tests simples
Permisos: workspace-write + execute
Coste estimado: Medio: generacion y ejecucion

## Objetivo

Generar tests que cubran comportamiento real y no snapshots decorativos.

## Tareas

1. Revisar convenciones de tests.
2. Pedir matriz de casos.
3. Generar unit test.
4. Ejecutar test y ajustar.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
