# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Revisar convenciones de tests.
2. Pedir matriz de casos.
3. Generar unit test.
4. Ejecutar test y ajustar.

## Solucion esperada

La entrega incluye al menos un test significativo y comando de verificacion.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
