# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Revisar mcp.json.
2. Configurar GitHub MCP readonly.
3. Consultar issue o PR de practica.
4. Registrar riesgo y valor.

## Solucion esperada

El inventario debe explicar fuente, permisos, datos, valor y prohibiciones.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
