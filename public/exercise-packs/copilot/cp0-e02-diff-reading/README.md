# Leer diff antes de aceptar magia

Vendor: copilot
Curso: Git/GitHub Survival para IA
Duracion: 20 min
Superficie: VS Code diff
Modelo recomendado: Modelo incluido / Ask
Permisos: read-only
Coste estimado: Muy bajo: una explicacion corta

## Objetivo

Leer un diff como evidencia: que cambia, que riesgo mete, que test falta y que pregunta haria un reviewer.

## Tareas

1. Abrir un diff pequeno.
2. Pedir a Copilot que lo explique.
3. Separar cambio funcional de ruido.
4. Escribir dos comentarios de review.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
