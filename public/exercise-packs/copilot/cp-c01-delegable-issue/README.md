# Issue delegable para cloud agent

Vendor: copilot
Curso: Copilot Cloud Agent Enterprise
Duracion: 45 min
Superficie: GitHub issue
Modelo recomendado: Copilot cloud agent
Permisos: repo policy + human review
Coste estimado: Medio/alto: premium requests + Actions minutes

## Objetivo

Preparar un issue que Copilot cloud agent pueda ejecutar sin preguntar lo basico ni tocar alcance peligroso.

## Tareas

1. Usar plantilla de issue.
2. Definir acceptance criteria.
3. Marcar archivos y restricciones.
4. Definir presupuesto y review humana.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
