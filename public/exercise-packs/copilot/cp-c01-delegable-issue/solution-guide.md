# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Usar plantilla de issue.
2. Definir acceptance criteria.
3. Marcar archivos y restricciones.
4. Definir presupuesto y review humana.

## Solucion esperada

El issue final incluye objetivo, contexto, restricciones, criterios, coste esperado y politica de review.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
