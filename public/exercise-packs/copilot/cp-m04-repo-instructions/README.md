# Copilot instructions de repositorio

Vendor: copilot
Curso: Copilot Medium
Duracion: 45 min
Superficie: .github/copilot-instructions.md
Modelo recomendado: Modelo incluido
Permisos: workspace-write
Coste estimado: Bajo

## Objetivo

Crear instrucciones persistentes cortas para que Copilot respete stack, comandos, seguridad y forma de cierre.

## Tareas

1. Leer plantilla.
2. Adaptar stack y comandos reales.
3. Anadir reglas de seguridad.
4. Pedir a Copilot que la critique por exceso de longitud.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
