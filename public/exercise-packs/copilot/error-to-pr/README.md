# Copilot Exercise Pack - Error to PR

Objetivo: convertir un error en una PR revisable usando Ask, Edit y Agent con criterio.

Flujo:
1. Abre `starter/`.
2. Usa `prompts.md` en Copilot Ask.
3. Aplica patch acotado con Edit.
4. Usa Agent solo para test, docs o PR summary.
5. Compara `expected.diff`.
6. Evalua con `rubric.md`.
