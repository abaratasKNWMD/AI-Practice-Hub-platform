# Rubrica - Copilot Error to PR

| Criterio | Excelente | Insuficiente |
|---|---|---|
| Ask | Diagnostica sin tocar codigo | Pide fix directo |
| Edit | Diff pequeno y localizado | Refactor amplio |
| Agent | Se usa con contrato | Se usa para tarea ambigua |
| Test | Cubre caso legacy | Solo prueba caso feliz |
| PR | Explica cambio, evidencia y riesgo | Descripcion generica |
