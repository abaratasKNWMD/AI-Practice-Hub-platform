# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Crear instruction file con applyTo.
2. Definir reglas especificas.
3. Probar una tarea que lo active.
4. Comparar con instruccion global.

## Solucion esperada

El resultado incluye al menos dos instruction files con patrones y reglas especificas.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
