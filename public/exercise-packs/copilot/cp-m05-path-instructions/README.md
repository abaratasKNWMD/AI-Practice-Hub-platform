# Path-specific instructions

Vendor: copilot
Curso: Copilot Medium
Duracion: 40 min
Superficie: .github/instructions
Modelo recomendado: Modelo incluido
Permisos: workspace-write
Coste estimado: Bajo

## Objetivo

Separar reglas de frontend, backend, tests y review para que Copilot cargue contexto mas fino.

## Tareas

1. Crear instruction file con applyTo.
2. Definir reglas especificas.
3. Probar una tarea que lo active.
4. Comparar con instruccion global.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
