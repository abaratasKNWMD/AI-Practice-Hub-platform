# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Definir MCPs permitidos.
2. Completar inventario.
3. Separar secrets/vars.
4. Crear politica de expiracion.

## Solucion esperada

La politica define servidores, tools, datos, owners, caducidad y excepciones.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
