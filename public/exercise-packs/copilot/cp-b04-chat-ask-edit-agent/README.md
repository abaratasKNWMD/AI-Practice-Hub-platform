# Ask, Edit y Agent: tres velocidades

Vendor: copilot
Curso: Copilot Basic
Duracion: 35 min
Superficie: Copilot Chat VS Code
Modelo recomendado: Modelo incluido para Ask/Edit; escalar solo si hay ambiguedad
Permisos: read-only -> workspace-write
Coste estimado: Bajo/medio segun modo y modelo

## Objetivo

Aprender a elegir Ask para entender, Edit para cambios acotados y Agent para tareas multiarchivo.

## Tareas

1. Hacer una pregunta en Ask.
2. Aplicar un cambio pequeno con Edit.
3. Definir una tarea que justificaria Agent.
4. Registrar cuando no usarias Agent.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
