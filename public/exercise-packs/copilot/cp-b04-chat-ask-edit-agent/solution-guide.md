# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Hacer una pregunta en Ask.
2. Aplicar un cambio pequeno con Edit.
3. Definir una tarea que justificaria Agent.
4. Registrar cuando no usarias Agent.

## Solucion esperada

El alumno debe terminar con una tabla de decision por modo y un ejemplo ejecutado con evidencia.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
