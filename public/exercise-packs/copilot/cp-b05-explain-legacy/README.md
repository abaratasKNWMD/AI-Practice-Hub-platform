# Explain de codigo legacy

Vendor: copilot
Curso: Copilot Basic
Duracion: 25 min
Superficie: Copilot Chat VS Code
Modelo recomendado: Modelo incluido / Ask
Permisos: read-only
Coste estimado: Bajo

## Objetivo

Usar Copilot para entender codigo viejo sin inventar arquitectura ni tocar archivos.

## Tareas

1. Seleccionar un archivo legacy.
2. Pedir explicacion con responsabilidades y flujo de datos.
3. Pedir riesgos y primer cambio seguro.
4. Guardar el resumen.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
