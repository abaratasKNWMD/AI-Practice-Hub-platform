# Revisar PR generado por agente

Vendor: copilot
Curso: Copilot Cloud Agent Enterprise
Duracion: 60 min
Superficie: GitHub PR
Modelo recomendado: Copilot code review + humano
Permisos: review-only
Coste estimado: Medio: review y re-review

## Objetivo

Aplicar politica de PRs generadas por IA: evidencia, tests, riesgo y responsabilidad humana.

## Tareas

1. Leer PR simulado.
2. Ejecutar review con instrucciones.
3. Clasificar findings.
4. Decidir merge, cambios o cierre.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
