# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Leer PR simulado.
2. Ejecutar review con instrucciones.
3. Clasificar findings.
4. Decidir merge, cambios o cierre.

## Solucion esperada

La decision final debe ser defendible: aprobar, pedir cambios o cerrar con evidencia.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
