# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Abrir la pantalla rota o revisar captura.
2. Pedir diagnostico visual con hipotesis verificables.
3. Aplicar un patch pequeno.
4. Revisar desktop y mobile.

## Solucion esperada

El resultado deseado es una correccion UI demostrada visualmente, con especial atencion a overflow, texto cortado, estados responsive y errores de consola.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
