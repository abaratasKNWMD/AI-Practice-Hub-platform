# Starter - Debug multimodal de UI

Este starter es generico para codex. Copialo a un repo de practica o usalo como contrato de arranque.

## Primer comando

```bash
node ../validator.mjs
```

## Donde empezar

1. Lee `../prompts.md`.
2. Usa `../mock-data/input.json`.
3. Completa la evidencia.
4. Ejecuta el validator.
