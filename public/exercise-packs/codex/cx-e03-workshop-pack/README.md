# Pack autoconsumible de workshop

Vendor: codex
Curso: Operating Model
Duracion: 60 min
Superficie: course ops + workshops
Modelo recomendado: GPT-5.4
Permisos: workspace-write
Coste estimado: Medio: creacion de materiales

## Objetivo

Preparar un workshop que reduzca horas de formador: video corto, ejercicio, solucion, checklist y dudas para tutoria.

## Tareas

1. Elegir un reto de Codex.
2. Asociar un microvideo y material de apoyo.
3. Escribir solucion guiada.
4. Definir que dudas pasan a tutoria y cuales no.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
