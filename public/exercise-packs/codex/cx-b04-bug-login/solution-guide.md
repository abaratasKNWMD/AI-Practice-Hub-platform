# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Pedir a Codex que reproduzca o explique como reproduciria el bug.
2. Exigir un plan de dos o tres pasos antes del patch.
3. Aplicar la correccion minima.
4. Ejecutar el test relevante o documentar el bloqueo.

## Solucion esperada

Codex debe localizar el punto de fallo, aplicar una correccion pequena y demostrarla con test o caso manual. El valor pedagogico esta en que el alumno vea que planificar reduce coste y evita cambios laterales.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
