# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Definir schema de findings para review.
2. Probarlo con un diff de ejemplo.
3. Validar campos obligatorios.
4. Crear una salida humana a partir del JSON.

## Solucion esperada

El alumno termina con un contrato JSON usable en CI y un renderer humano. Esta pieza prepara swarms, jueces y automatizacion.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
