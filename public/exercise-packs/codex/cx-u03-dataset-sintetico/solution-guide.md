# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Seleccionar fuentes permitidas.
2. Generar ejemplos sinteticos con referencias.
3. Filtrar duplicados, secretos y respuestas no verificables.
4. Etiquetar por dominio, dificultad y riesgo.

## Solucion esperada

El output es un dataset semilla con trazabilidad, politicas de limpieza y criterios de evaluacion. Sirve para SLMs, onboarding y agentes internos de Codex.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
