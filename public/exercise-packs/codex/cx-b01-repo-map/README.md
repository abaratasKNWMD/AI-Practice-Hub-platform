# Mapa express del repositorio

Vendor: codex
Curso: Codex Basic
Duracion: 25 min
Superficie: CLI + editor
Modelo recomendado: GPT-5.4 Mini
Permisos: read-only
Coste estimado: Bajo: 1 exploracion corta, sin reintentos largos

## Objetivo

El alumno pide a Codex que entienda una base de codigo antes de tocar nada. El objetivo es salir con un mapa fiable de carpetas, puntos de entrada, tests y riesgos.

## Tareas

1. Abrir el repo de practica y pedir un mapa de arquitectura en 10 bullets.
2. Pedir a Codex que localice scripts de test, build y lint.
3. Identificar tres archivos criticos y justificar por que.
4. Cerrar con una lista de preguntas que un desarrollador senior haria antes de cambiar codigo.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
