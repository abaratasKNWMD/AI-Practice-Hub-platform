# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Definir coste objetivo por curso.
2. Clasificar tareas por coste esperado.
3. Crear umbrales de alerta.
4. Preparar una transparencia de buenas practicas.

## Solucion esperada

El output es una hoja de presupuesto que indica cuando usar Mini, cuando escalar y cuando parar para pedir criterio humano.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
