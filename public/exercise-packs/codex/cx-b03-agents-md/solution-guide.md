# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Revisar la plantilla AGENTS.example.md.
2. Adaptarla al repo con comandos reales y convenciones locales.
3. Anadir limites: no tocar secretos, no reordenar imports masivos, no reescribir tests sin motivo.
4. Pedir a Codex que critique el AGENTS.md como si fuera onboarding de un nuevo dev.

## Solucion esperada

La solucion esperada es un AGENTS.md breve, con comandos de verificacion, convenciones de edicion, politicas de permisos y un protocolo de cierre. No debe ser una novela: debe ayudar a Codex a tomar mejores decisiones.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
