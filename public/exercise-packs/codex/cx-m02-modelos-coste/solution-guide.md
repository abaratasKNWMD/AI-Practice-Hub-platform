# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Clasificar 10 tareas por modelo recomendado.
2. Estimar coste relativo antes de ejecutar.
3. Registrar resultado, calidad y si hubo reintento.
4. Definir una politica de escalado de modelo.

## Solucion esperada

El alumno debe terminar con una matriz de decision: Mini para lectura y cambios pequenos, GPT-5.4 para implementacion estandar, GPT-5.5 para arquitectura, bugs profundos, multimodal y tareas de alto riesgo.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
