# Selector de modelo y coste

Vendor: codex
Curso: Codex Potente
Duracion: 40 min
Superficie: model picker + cost log
Modelo recomendado: GPT-5.4 Mini, GPT-5.4, GPT-5.5
Permisos: read-only
Coste estimado: Variable: se compara barato, medio y premium

## Objetivo

Aprender a elegir modelo por riesgo, no por ego: rapido para tareas mecanicas, fuerte para arquitectura, multimodal para UI.

## Tareas

1. Clasificar 10 tareas por modelo recomendado.
2. Estimar coste relativo antes de ejecutar.
3. Registrar resultado, calidad y si hubo reintento.
4. Definir una politica de escalado de modelo.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
