# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Escribir una peticion vaga tipo arregla el login.
2. Reescribirla con objetivo, contexto, restricciones y definicion de terminado.
3. Comparar las dos respuestas de Codex.
4. Guardar el prompt final en la plantilla de prompts.

## Solucion esperada

El prompt final debe indicar que se analice antes de editar, que no se cambie comportamiento no relacionado, que se proponga un plan y que se valide con tests o explicacion de por que no se pudieron ejecutar.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
