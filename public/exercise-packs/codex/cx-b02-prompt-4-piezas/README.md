# Prompt de cuatro piezas

Vendor: codex
Curso: Codex Basic
Duracion: 20 min
Superficie: chat Codex
Modelo recomendado: GPT-5.4 Mini
Permisos: read-only
Coste estimado: Muy bajo: una iteracion de prompt y una revision

## Objetivo

Transformar una peticion vaga en un briefing accionable: objetivo, contexto, restricciones y criterio de aceptacion.

## Tareas

1. Escribir una peticion vaga tipo arregla el login.
2. Reescribirla con objetivo, contexto, restricciones y definicion de terminado.
3. Comparar las dos respuestas de Codex.
4. Guardar el prompt final en la plantilla de prompts.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
