# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Leer la skill QA visual incluida.
2. Adaptar checklist a la aplicacion de practica.
3. Ejecutar una verificacion manual o automatizada.
4. Registrar findings y accion recomendada.

## Solucion esperada

La skill final debe guiar a Codex para abrir la app, revisar consola, comprobar responsive, detectar textos solapados y cerrar con evidencias.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
