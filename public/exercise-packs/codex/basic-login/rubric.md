# Rubrica - Codex Basic Login

| Criterio | Excelente | Insuficiente |
|---|---|---|
| Mapa read-only | Identifica flujo, archivo y test antes de editar | Edita sin diagnostico |
| Scope | Toca maximo source y test cercano | Refactoriza auth completa |
| Prompt | Incluye objetivo, rutas, restricciones y done | Pide "arregla login" |
| Verificacion | Ejecuta o documenta test cercano | Cierra sin evidencia |
| Handoff | Incluye diff, check, riesgo y siguiente accion | Resume genericamente |
