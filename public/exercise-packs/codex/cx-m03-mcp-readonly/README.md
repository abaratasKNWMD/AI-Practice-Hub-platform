# MCP read-only con contexto externo

Vendor: codex
Curso: Codex Potente
Duracion: 45 min
Superficie: MCP + docs + repo
Modelo recomendado: GPT-5.4
Permisos: read-only con conectores
Coste estimado: Medio: mas contexto recuperado, pocas ediciones

## Objetivo

Conectar fuentes externas sin abrir puertas innecesarias. El alumno practica inventario, alcance y evidencias.

## Tareas

1. Completar el inventario MCP con fuente, permisos y riesgo.
2. Simular una consulta a documentacion externa.
3. Pedir a Codex que distinga evidencia de inferencia.
4. Crear una regla de uso para el equipo.

## Evidencia esperada

- Prompt inicial usado.
- Resultado o diff producido.
- Validacion ejecutada o bloqueo documentado.
- Coste/modelo/permisos registrados.
- Nota final para tutoria si queda duda.
