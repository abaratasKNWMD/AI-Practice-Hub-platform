# Solucion guiada

## Lectura

Empieza por confirmar objetivo, superficie, permisos y coste.

## Ejecucion

1. Completar el inventario MCP con fuente, permisos y riesgo.
2. Simular una consulta a documentacion externa.
3. Pedir a Codex que distinga evidencia de inferencia.
4. Crear una regla de uso para el equipo.

## Solucion esperada

El resultado valido es una decision documentada: que MCP se usa, para que, con que permisos, que datos toca y como se verifica la respuesta.

## Cierre

El ejercicio queda cerrado cuando existe evidencia verificable y el alumno puede explicar que aceptaria o rechazaria en una review.
