# Guion minuto a minuto

| Minuto | Bloque | Accion del instructor | Evidencia |
| --- | --- | --- | --- |
| 00-05 | Contrato | Explicar objetivo, limites y output final. | Alumno entiende que no se explica Git. |
| 05-10 | Intake | Convertir peticion ambigua en briefing de 4 piezas. | Briefing escrito. |
| 10-15 | Explorer | Pedir mapa readonly a Codex. | Rutas y riesgos. |
| 15-20 | Modelo/permisos | Elegir modelo, effort y permiso. | Decision registrada. |
| 20-25 | Plan | Pedir plan corto antes de editar. | Plan aceptado o corregido. |
| 25-35 | Patch | Aplicar cambio minimo. | Diff pequeno. |
| 35-45 | Tests | Agregar y ejecutar prueba de regresion. | Red/green o salida equivalente. |
| 45-50 | Rescate | Mostrar que hacer si falla. | Prompt de diagnostico. |
| 50-55 | Review | Revisar diff con rubrica. | Findings accionables. |
| 55-60 | PR | Crear PR body y cost ledger. | Handoff completo. |
