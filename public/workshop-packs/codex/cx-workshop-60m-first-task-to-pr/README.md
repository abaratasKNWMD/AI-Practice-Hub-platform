# Workshop 1h Codex - First task to PR

Objetivo: que el alumno convierta una peticion ambigua en un diff probado, revisado y listo para PR usando Codex.

Video simulado: `/player/cx-workshop-60m-first-task-to-pr`

Ruta recomendada:

1. Ver los primeros 10 minutos del video.
2. Ejecutar el starter `cx-b04-bug-login`.
3. Usar los prompts de este pack.
4. Cerrar con PR body, test y cost ledger.

Entregables del alumno:

- Briefing de 4 piezas.
- Mapa readonly del repo.
- Plan antes de patch.
- Diff minimo.
- Test de regresion.
- Review estructurada.
- Registro de coste.

- `minute-by-minute.md`
