## Preguntas de control

- Que parte del prompt reduce mas tokens?
- Que permiso necesita cada fase?
- Que evidencia hace que el PR sea revisable?
- Que cambio no deberia tocar Codex?

## Rubrica rapida

| Criterio | Aprobado |
| --- | --- |
| Alcance | El diff toca solo lo necesario. |
| Tests | Hay prueba que captura el bug. |
| Review | Findings accionables o aprobacion razonada. |
| Coste | Modelo y permiso justificados. |
| Handoff | PR body claro y breve. |
