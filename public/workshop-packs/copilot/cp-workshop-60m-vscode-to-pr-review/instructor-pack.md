# Pack instructor

## Preparacion

- Abrir VS Code con el starter de carrito.
- Tener visibles Chat, Edit y Agent.
- Preparar una issue pequena y una salida de test.

## Preguntas de control

- Por que Ask antes que Agent?
- Que informacion necesita Edit para no tocar de mas?
- Cuando compensa Agent?
- Que cuenta como review accionable?

## Rubrica rapida

| Criterio | Aprobado |
| --- | --- |
| Modo | La superficie elegida se justifica. |
| Scope | El patch queda localizado. |
| Tests | Hay prueba de regresion. |
| Review | Findings concretos. |
| Coste | Premium request justificada por outcome. |
