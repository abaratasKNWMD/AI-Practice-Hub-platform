## Puntos que conviene comprobar antes de impartir

- Modelo recomendado para Codex y APIs.
- Coste de Batch, embeddings, evals, fine-tuning y storage.
- Disponibilidad regional y requisitos de Zero Data Retention.
- Estado de features beta o experimentales.
- Cambios en schemas de `config.toml`, subagentes, skills y MCP.

## Frase para clase

No vendas una API concreta como dogma. Vende el patron: contratos de entrada/salida, trazas, evals, gates humanos y evidencia reproducible.
