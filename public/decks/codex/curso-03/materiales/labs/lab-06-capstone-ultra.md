# Lab 06: Capstone Codex Ultra

## Objetivo

Unir PR swarm, Batch planner, dataset sintetico, RAG mini y rubrica de juez en un flujo demostrable.

## Duracion

60 minutos.

## Entregable

Un README de adopcion para un repo real con:

- arquitectura del sistema;
- contratos de agentes;
- MCPs necesarios;
- datasets y evals;
- politica de coste;
- gates humanos;
- roadmap de 60 dias.

## Prompt para Codex

```text
Usa los materiales del Curso 3 para crear un plan de adopcion Codex Ultra para este repo.

Incluye:
- PR swarm minimo;
- RAG de codigo;
- pipeline Batch candidato;
- dataset sintetico;
- evals y juez;
- riesgos de seguridad;
- presupuesto cualitativo;
- primera semana de implementacion.

No vendas magia. Senala limites, gates humanos y condiciones de parada.
```

## Cierre

El capstone no busca una demo enorme. Busca que el alumno pueda explicar como gobernaria Codex Ultra en su organizacion.
