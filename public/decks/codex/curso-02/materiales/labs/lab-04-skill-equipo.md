# Lab 04: skill de equipo

## Objetivo

Convertir un workflow repetible en una skill pequeña.

## Material

- `../skills/qa-visual-codex/SKILL.md`
- `../prompts-potentes.md`

## Pasos

1. Lee la skill de QA visual.
2. Identifica trigger, inputs, pasos y done.
3. Adapta la skill a un workflow del equipo:
   - review backend;
   - release notes;
   - migración de schema;
   - diagnóstico Sentry;
   - QA visual.
4. Pide a Codex que critique si la skill está demasiado amplia.

## Cierre

Una skill buena no es un manual entero: es una receta que Codex sabe cuándo cargar.
