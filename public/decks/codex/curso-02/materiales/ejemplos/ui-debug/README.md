# UI debug multimodal

Ejemplo estático para practicar captura + código.

## Uso

Abre `index.html` en navegador. En viewport móvil, la barra de acciones fija puede tapar el final del panel de contenido. El objetivo del lab es pedir a Codex un cambio mínimo de CSS y verificar visualmente.

## Archivos

- `index.html`: estructura.
- `styles.css`: bug visual deliberado.

Usa el prompt de debug multimodal de `../../prompts-potentes.md`.
